## ✨ Destaques

### Moldura Aprimorada
- Colunas pergaminho com textura de madeira envelhecida
- Alças rolete ornamentadas com padrão concêntrico
- Padrão de madeira (linhas verticais + grade horizontal)
- Sombras/reflexos para profundidade

### Paisagens Sumi-E (Novo)
- Árvore estilizada esquerda: tronco + galhos + folhagem
- Árvore espelhada direita: balanceamento visual
- Cores tinta amortecida com variações sutis
- Inspiradas pela sua referência visual

### Truncamento de Texto
- "[E] Iai Flash (Ataque)" → "[E] Iai Flash"
- Todos os comandos cabem nos cards (155px max)
- Sem perda de dados (truncamento é visual)
